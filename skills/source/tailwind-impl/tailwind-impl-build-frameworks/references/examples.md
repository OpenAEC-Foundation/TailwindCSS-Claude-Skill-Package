# Reference : Framework Integration Examples

Complete copy-paste starter projects for Astro, SvelteKit, Nuxt,
and Remix. Each example is the **minimum working project** for that
framework + Tailwind version combination.

---

## Example 1 : Astro 5 + Tailwind v4

`package.json` excerpt :

```json
{
  "dependencies": {
    "astro": "^5.0.0",
    "tailwindcss": "^4.0.0",
    "@tailwindcss/vite": "^4.0.0"
  }
}
```

`astro.config.mjs` :

```js
import { defineConfig } from "astro/config"
import tailwindcss from "@tailwindcss/vite"

export default defineConfig({
  vite: {
    plugins: [tailwindcss()],
  },
})
```

`src/styles/global.css` :

```css
@import "tailwindcss";
```

`src/layouts/Layout.astro` :

```astro
---
import "../styles/global.css"
---
<html lang="en">
  <body>
    <slot />
  </body>
</html>
```

`src/pages/index.astro` :

```astro
---
import Layout from "../layouts/Layout.astro"
---
<Layout>
  <h1 class="text-3xl font-bold underline">Hello Astro + Tailwind v4</h1>
</Layout>
```

Run : `npm run dev`.

## Example 2 : Astro 4 + Tailwind v3

Install :

```bash
npx astro add tailwind
```

Accept the prompts. Generated files :

`astro.config.mjs` (auto-edited) :

```js
import { defineConfig } from "astro/config"
import tailwind from "@astrojs/tailwind"

export default defineConfig({
  integrations: [tailwind()],
})
```

`tailwind.config.mjs` (auto-generated) :

```js
/** @type {import('tailwindcss').Config} */
export default {
  content: ["./src/**/*.{astro,html,js,jsx,md,mdx,svelte,ts,tsx,vue}"],
  theme: { extend: {} },
  plugins: [],
}
```

`src/pages/index.astro` :

```astro
<h1 class="text-3xl font-bold underline">Hello Astro + Tailwind v3</h1>
```

The integration auto-injects base styles. No manual entry CSS needed.

## Example 3 : SvelteKit + Tailwind v4

`vite.config.ts` :

```ts
import { sveltekit } from "@sveltejs/kit/vite"
import { defineConfig } from "vite"
import tailwindcss from "@tailwindcss/vite"

export default defineConfig({
  plugins: [tailwindcss(), sveltekit()],
})
```

`src/app.css` :

```css
@import "tailwindcss";
```

`src/routes/+layout.svelte` :

```svelte
<script>
  import "../app.css"
  let { children } = $props()
</script>

{@render children()}
```

`src/routes/+page.svelte` :

```svelte
<h1 class="text-3xl font-bold underline">Hello SvelteKit + Tailwind v4</h1>
```

For scoped styles with `@apply` :

```svelte
<style>
  @reference "../app.css";

  .card {
    @apply rounded-lg bg-white p-4 shadow;
  }
</style>
```

## Example 4 : SvelteKit + Tailwind v3

`svelte.config.js` :

```js
import adapter from "@sveltejs/adapter-auto"
import { vitePreprocess } from "@sveltejs/kit/vite"

export default {
  preprocess: vitePreprocess(),
  kit: { adapter: adapter() },
}
```

`tailwind.config.js` :

```js
export default {
  content: ["./src/**/*.{html,js,svelte,ts}"],
  theme: { extend: {} },
  plugins: [],
}
```

`postcss.config.js` (generated by `init -p`) :

```js
export default {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
}
```

`src/app.css` :

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

`src/routes/+layout.svelte` :

```svelte
<script>
  import "../app.css"
</script>

<slot />
```

Scoped styles need `lang="postcss"` :

```svelte
<style lang="postcss">
  .card {
    @apply rounded-lg bg-white p-4 shadow;
  }
</style>
```

## Example 6 : Nuxt 3 + Tailwind v3 (module path)

```bash
npm install -D @nuxtjs/tailwindcss
```

`nuxt.config.ts` :

```ts
export default defineNuxtConfig({
  modules: ["@nuxtjs/tailwindcss"],
})
```

That's the entire setup. The module auto-creates a default
`tailwind.config.js` and injects the stylesheet.

To customize, add `tailwind.config.ts` at the project root :

```ts
import type { Config } from "tailwindcss"

export default {
  content: [
    "./components/**/*.{vue,js,ts}",
    "./layouts/**/*.vue",
    "./pages/**/*.vue",
    "./app.vue",
  ],
  theme: {
    extend: {
      colors: {
        brand: "#3b82f6",
      },
    },
  },
  plugins: [],
} satisfies Config
```

`app.vue` :

```vue
<template>
  <h1 class="text-3xl font-bold underline">Hello Nuxt + Tailwind v3</h1>
</template>
```

## Example 7 : Remix 2 (Vite) + Tailwind v4

`vite.config.ts` :

```ts
import { defineConfig } from "vite"
import { vitePlugin as remix } from "@remix-run/dev"
import tailwindcss from "@tailwindcss/vite"

export default defineConfig({
  plugins: [tailwindcss(), remix()],
})
```

`app/tailwind.css` :

```css
@import "tailwindcss";
```

`app/root.tsx` :

```tsx
import type { LinksFunction } from "@remix-run/node"
import {
  Links, Meta, Outlet, Scripts, ScrollRestoration,
} from "@remix-run/react"
import stylesheet from "~/tailwind.css?url"

export const links: LinksFunction = () => [
  { rel: "stylesheet", href: stylesheet },
]

export default function App() {
  return (
    <html lang="en">
      <head>
        <Meta />
        <Links />
      </head>
      <body>
        <Outlet />
        <ScrollRestoration />
        <Scripts />
      </body>
    </html>
  )
}
```

`app/routes/_index.tsx` :

```tsx
export default function Index() {
  return <h1 className="text-3xl font-bold underline">Hello Remix + Tailwind v4</h1>
}
```

## Example 9 : SvelteKit v4 + safelist for dynamic classes

`src/app.css` :

```css
@import "tailwindcss";

@source inline "{bg-red-500,bg-green-500,bg-blue-500}";
@source inline "{text-(red|green|blue)-(100,500,900)}";
```

`src/lib/Badge.svelte` :

```svelte
<script lang="ts">
  export let color: "red" | "green" | "blue"
</script>

<span class="bg-{color}-500 text-white">{color}</span>
```

The class name `bg-{color}-500` is invisible to the static scanner.
`@source inline` brace expansion guarantees the classes are emitted.

## Example 10 : Nuxt v4 with shared component package

Monorepo layout :

```
repo/
├── apps/web/
│   ├── nuxt.config.ts
│   └── app/assets/css/main.css
└── packages/ui/
    └── components/Button.vue
```

`apps/web/app/assets/css/main.css` :

```css
@import "tailwindcss";
@source "../../../../packages/ui/components/**/*.vue";
```

The `@source` path is relative to the CSS file. Without it, classes
inside `packages/ui` produce no CSS.

## Example 11 : Astro v4 with brand color tokens

`src/styles/global.css` :

```css
@import "tailwindcss";

@theme {
  --color-brand-50:  oklch(0.97 0.02 250);
  --color-brand-500: oklch(0.62 0.18 250);
  --color-brand-900: oklch(0.25 0.10 250);
  --font-display: "Inter", sans-serif;
}
```

`src/pages/index.astro` :

```astro
---
import "../styles/global.css"
---
<h1 class="text-brand-500 font-display text-4xl">Branded</h1>
```

The `--color-brand-*` tokens automatically produce `bg-brand-500`,
`text-brand-500`, `border-brand-500`, etc.

## Example 12 : Remix v4 with multiple stylesheets

`app/root.tsx` :

```tsx
import type { LinksFunction } from "@remix-run/node"
import tailwind from "~/tailwind.css?url"
import fonts from "~/fonts.css?url"

export const links: LinksFunction = () => [
  { rel: "stylesheet", href: fonts },
  { rel: "stylesheet", href: tailwind },
]
```

ALWAYS list base / font stylesheets BEFORE the Tailwind stylesheet so
Tailwind's preflight overrides browser defaults but not your fonts.

## Verifying any setup

Drop this snippet in the framework's root template :

```html
<div class="text-3xl font-bold underline">utility</div>
<div class="text-[#ff00aa] h-[42vh]">arbitrary</div>
<div class="md:text-lg dark:bg-gray-800">variant</div>
```

If all three render with the intended styles, the integration is fully wired.
